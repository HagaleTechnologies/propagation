# M4 — Serving + Prediction Surface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A scheduled batch-inference path that every 15 minutes scores the active path-cell universe and publishes a validated `propagation.prediction-surface.v1` JSON document, plus the model registry, weekly guarded retrain, and a daily live scoreboard (yesterday's predictions vs. what actually happened).

**Architecture:** Pure batch: `serve-score --once` loads the latest registered per-horizon GBT models, scores cells labeled in the trailing 28 days, quantizes per the contract, validates against `contracts/prediction-surface.v1.schema.json` (publish is refused on any failure), and atomically writes `surfaces/current.json` plus a timestamped archive copy. launchd fires it every 15 minutes on the Mac. A registry directory holds versioned model artifacts with the confidence-tier metadata; a weekly retrain promotes a new version only if it is not worse on Brier; the scoreboard job joins archived surfaces against realized labels daily.

**Tech Stack:** Python 3.11+/uv, polars, DuckDB (via M0's `Lake`), LightGBM artifacts (via M2's `GBTModel`), `jsonschema`, launchd (macOS).

**Out of scope (closed-side, deliberate):** the cqdx adapter, KV/D1 publishing, "band outlook" UI, and pancetta wiring live in cqdx, not here. This plan ends at a validated surface on disk/object storage plus a consumer-facing integration note (`docs/INTEGRATION-cqdx.md`). The contract's promotion into `dispensa` is ADR-pending — mentioned in the note, not performed here.

**Prerequisites:** M0–M3 complete: the lake has labels across bands, and M2/M3 registered training produced per-horizon `GBTModel` artifacts loadable via `GBTModel.load`. Execute on branch `feat/m4-serving`; land by PR.

## Global Constraints

(Copied from `docs/superpowers/plans/2026-07-09-INTERFACES.md`; every task below implicitly includes these.)

- Python **3.11+**, `uv`-managed. `ruff` + `pytest`. License: MIT OR Apache-2.0.
- Layout: `src/propagation/…` (src layout), tests mirror under `tests/`.
- Lake root defaults to `./data/lake` (gitignored); every CLI takes
  `--lake-root` to override. Reports/artifacts to `./reports` (gitignored).
- All timestamps UTC. Polars dtype `pl.Datetime("us", "UTC")`; Parquet
  `timestamp[us, tz=UTC]`.
- 15-min windows aligned to UTC boundaries (minute ∈ {0,15,30,45}); a spot
  belongs to the window containing its `ts` (floor). Cells are directional.
- Supported bands (closed set, order canonical):
  `["160m","80m","60m","40m","30m","20m","17m","15m","12m","10m","6m"]`
- **No cqdx imports, ever.** `extract-cqdx` is optional, env-gated
  (`CQDX_R2_*` vars), behind the same extractor interface as public sources.
- Blocked time-series CV, gap ≥ 48 h; eval always on the FULL label set;
  no random splits. Δ_avail = 5 min availability buffer on all
  autoregressive features (train and serve identically).
- Sampling determinism: negatives 3:1 per (band, UTC date) stratum,
  `numpy.random.Generator(numpy.random.PCG64(seed))` with
  `seed = int.from_bytes(hashlib.sha256(f"{band}|{date_iso}".encode()).digest()[:8], "big") & 0xFFFFFFFF`
  where `date_iso` is `YYYY-MM-DD`.
- Conventional commits (`feat:`, `test:`, `chore:`, `docs:`); each milestone
  executes on its own branch, lands by PR. Main moves only by PR merge.

**M4-pinned decisions (from the interface contract + this plan):**

- Canonical horizons: `[0, 3600, 10800, 21600, 43200, 86400]` seconds.
- `p_open_pct` quantization: `round(p * 100)` — Python's built-in `round`, i.e. round-half-even — clamped to [0, 100]. `null` = abstain, passed through.
- SNR abstain rule: `p_open < 0.10` → SNR slot is `null`. SNR integer dB clamped to the schema range [−40, 60].
- Confidence tiers: per-cell training-label counts; tercile boundaries `(lo, hi)` computed at train time and stored in the model record; tier = 0 if `n < lo`, 1 if `lo ≤ n < hi`, 2 if `n ≥ hi`. Cells absent from training density → tier 0.
- Scoring universe: distinct `(tx_field, rx_field, band)` with ≥1 label in the trailing 28 days before `valid_from`.
- `valid_until = valid_from + 30 min` (per the schema's stated norm).
- Registry layout: `models/registry/{model_id}/{version}/` containing `record.json`, `model-h{horizon_s}.txt` per horizon, `cell_density.parquet`. Version string `YYYY.MM.DD` (lexicographically sortable).
- Retrain guardrail: promote only if candidate Brier ≤ previous Brier + 0.002 at **every** horizon, evaluated on the trailing 7 full UTC days (full unsampled label set), train data ending 48 h before the eval window. No previous record → promote unconditionally.
- Surfaces are written atomically (`os.replace` from a same-directory temp file). Validation failure → nothing is published, process exits non-zero.

```python
"""Model artifact registry: versioned records under models/registry/.

Layout: {registry_dir}/{model_id}/{version}/
    record.json            # metadata incl. per-horizon model file names
    model-h{horizon}.txt   # one artifact per horizon (GBTModel.save output)
    cell_density.parquet   # per-cell training-label counts (confidence tiers)
"""

from __future__ import annotations

import json
import shutil
from dataclasses import dataclass
from datetime import date
from pathlib import Path

import polars as pl

RECORD_NAME = "record.json"
DENSITY_NAME = "cell_density.parquet"


@dataclass(frozen=True)
class ModelRecord:
    model_id: str
    version: str
    trained_through: date
    path: Path  # the version directory


def write_record(
    registry_dir: Path,
    model_id: str,
    version: str,
    trained_through: date,
    model_files: dict[int, Path],
    cell_density: pl.DataFrame,
    confidence_bounds: tuple[float, float],
) -> ModelRecord:
    vdir = registry_dir / model_id / version
    vdir.mkdir(parents=True, exist_ok=True)
    stored: dict[str, str] = {}
    for horizon_s, src in sorted(model_files.items()):
        name = f"model-h{horizon_s}.txt"
        shutil.copyfile(src, vdir / name)
        stored[str(horizon_s)] = name
    cell_density.write_parquet(vdir / DENSITY_NAME)
    meta = {
        "model_id": model_id,
        "version": version,
        "trained_through": trained_through.isoformat(),
        "model_files": stored,
        "confidence_bounds": list(confidence_bounds),
    }
    (vdir / RECORD_NAME).write_text(json.dumps(meta, indent=2))
    return ModelRecord(
        model_id=model_id, version=version, trained_through=trained_through, path=vdir
    )


def latest(registry_dir: Path, model_id: str) -> ModelRecord:
    mdir = registry_dir / model_id
    versions = (
        sorted(d.name for d in mdir.iterdir() if (d / RECORD_NAME).exists())
        if mdir.exists()
        else []
    )
    if not versions:
        raise FileNotFoundError(f"no registry records for {model_id!r} under {registry_dir}")
    vdir = mdir / versions[-1]
    meta = json.loads((vdir / RECORD_NAME).read_text())
    return ModelRecord(
        model_id=meta["model_id"],
        version=meta["version"],
        trained_through=date.fromisoformat(meta["trained_through"]),
        path=vdir,
    )


def record_meta(record: ModelRecord) -> dict:
    return json.loads((record.path / RECORD_NAME).read_text())


def model_file(record: ModelRecord, horizon_s: int) -> Path:
    meta = record_meta(record)
    try:
        return record.path / meta["model_files"][str(horizon_s)]
    except KeyError:
        raise FileNotFoundError(
            f"{record.model_id} {record.version} has no model for horizon {horizon_s}s"
        ) from None


def cell_density(record: ModelRecord) -> pl.DataFrame:
    return pl.read_parquet(record.path / DENSITY_NAME)
```

```python
"""Batch inference -> prediction-surface.v1 JSON (ARCHITECTURE §7).

Publisher-side invariants the JSON Schema cannot express (SPEC-contract-notes:
"all arrays have length n_cells" / per-horizon inner arrays match horizons_s)
are enforced here at runtime; publishing is refused on any validation failure.
"""

from __future__ import annotations

import json
from pathlib import Path

import jsonschema

HORIZONS_S = [0, 3600, 10800, 21600, 43200, 86400]
SNR_ABSTAIN_BELOW = 0.10
UNIVERSE_LOOKBACK_DAYS = 28

_SCHEMA_PATH = (
    Path(__file__).resolve().parents[3]
    / "contracts"
    / "prediction-surface.v1.schema.json"
)


class SurfaceValidationError(Exception):
    """The assembled surface violates the v1 contract; do not publish."""


def load_schema(path: Path | None = None) -> dict:
    return json.loads((path or _SCHEMA_PATH).read_text())


def quantize_p_open(p: float | None) -> int | None:
    """Probability -> integer percent. round() is round-half-even by design
    (SPEC-contract-notes: integer quantization avoids float-formatting drift)."""
    if p is None:
        return None
    return min(100, max(0, round(p * 100)))


def quantize_snr(snr: float | None) -> int | None:
    if snr is None:
        return None
    return min(60, max(-40, round(snr)))


def validate_surface(doc: dict, schema: dict) -> None:
    try:
        jsonschema.validate(doc, schema)
    except jsonschema.ValidationError as e:
        raise SurfaceValidationError(f"schema validation failed: {e.message}") from e
    n = doc["n_cells"]
    cols = doc["columns"]
    for name in ("tx_field", "rx_field", "band", "p_open_pct", "confidence"):
        if len(cols[name]) != n:
            raise SurfaceValidationError(
                f"columns.{name} has {len(cols[name])} entries, expected n_cells={n}"
            )
    n_h = len(doc["horizons_s"])
    for name in ("p_open_pct", "snr_db_ft8eq_p50"):
        if name in cols:
            for i, inner in enumerate(cols[name]):
                if len(inner) != n_h:
                    raise SurfaceValidationError(
                        f"columns.{name}[{i}] has {len(inner)} horizons, expected {n_h}"
                    )
```

```python
from datetime import UTC, datetime, timedelta  # top of file

import polars as pl  # top of file

from propagation.serving import registry as _registry  # top of file
from propagation.serving.registry import ModelRecord  # top of file


def _iso(ts: datetime) -> str:
    return ts.astimezone(UTC).strftime("%Y-%m-%dT%H:%M:%SZ")


def confidence_tiers(
    cells: pl.DataFrame, density: pl.DataFrame, bounds: tuple[float, float]
) -> list[int]:
    """Tier per cell from training-label density (contract: 0=low,1=med,2=high)."""
    lo, hi = bounds
    joined = cells.join(density, on=["tx_field", "rx_field", "band"], how="left")
    counts = joined["n_labels"].fill_null(0).to_list()
    return [0 if n < lo else (1 if n < hi else 2) for n in counts]


def build_surface(
    models: dict[int, "object"],
    cells: pl.DataFrame,
    valid_from: datetime,
    record: ModelRecord,
    generated_at: datetime | None = None,
) -> dict:
    """Assemble a prediction-surface.v1 document (columnar; see the schema).

    `models` maps horizon seconds -> OpennessModel. For horizon h the target
    window is valid_from + h; prediction time is valid_from for every horizon.
    """
    meta = _registry.record_meta(record)
    horizons = sorted(models)
    n_cells = cells.height
    have_snr = bool(models) and all(hasattr(m, "predict_snr") for m in models.values())

    p_by_h: dict[int, list[int | None]] = {}
    snr_by_h: dict[int, list[int | None]] = {}
    for h in horizons:
        target = cells.select(
            pl.lit(valid_from + timedelta(seconds=h))
            .cast(pl.Datetime("us", "UTC"))
            .alias("window_start"),
            "tx_field",
            "rx_field",
            "band",
        )
        p_raw = models[h].predict_p_open(target)["p_open"].to_list()
        p_by_h[h] = [quantize_p_open(v) for v in p_raw]
        if have_snr:
            s_raw = models[h].predict_snr(target)["snr_ft8eq"].to_list()
            snr_by_h[h] = [
                None
                if (pv is None or pv < SNR_ABSTAIN_BELOW or sv is None)
                else quantize_snr(sv)
                for pv, sv in zip(p_raw, s_raw, strict=True)
            ]

    doc: dict = {
        "schema": "propagation.prediction-surface.v1",
        "generated_at": _iso(generated_at or datetime.now(UTC)),
        "valid_from": _iso(valid_from),
        "valid_until": _iso(valid_from + timedelta(minutes=30)),
        "model": {
            "id": record.model_id,
            "version": record.version,
            "trained_through": record.trained_through.isoformat(),
        },
        "reference": {"cell_scheme": "maidenhead-field", "snr": "ft8eq-2500hz-100w"},
        "horizons_s": horizons,
        "n_cells": n_cells,
        "columns": {
            "tx_field": cells["tx_field"].to_list(),
            "rx_field": cells["rx_field"].to_list(),
            "band": cells["band"].to_list(),
            "p_open_pct": [[p_by_h[h][i] for h in horizons] for i in range(n_cells)],
            "confidence": confidence_tiers(
                cells, _registry.cell_density(record), tuple(meta["confidence_bounds"])
            ),
        },
    }
    if have_snr:
        doc["columns"]["snr_db_ft8eq_p50"] = [
            [snr_by_h[h][i] for h in horizons] for i in range(n_cells)
        ]
    return doc
```

```python
def publish(doc: dict, surfaces_dir: Path) -> Path:
    """Atomically update current.json, then archive by valid_from. Consumers
    polling the stable URL never observe a partial document."""
    valid_from = datetime.strptime(doc["valid_from"], "%Y-%m-%dT%H:%M:%SZ").replace(
        tzinfo=UTC
    )
    surfaces_dir.mkdir(parents=True, exist_ok=True)
    payload = json.dumps(doc, separators=(",", ":"))
    current = surfaces_dir / "current.json"
    tmp = surfaces_dir / f".current.json.tmp-{os.getpid()}"
    try:
        tmp.write_text(payload)
        os.replace(tmp, current)
    finally:
        tmp.unlink(missing_ok=True)
    archive = surfaces_dir / f"{valid_from:%Y/%m/%d}" / f"{valid_from:%H%M}.json"
    archive.parent.mkdir(parents=True, exist_ok=True)
    archive.write_text(payload)
    return archive
```

```python
def scoring_cells(
    lake: Lake, valid_from: datetime, lookback_days: int = UNIVERSE_LOOKBACK_DAYS
) -> pl.DataFrame:
    """Activity-gated scoring universe: cells labeled in the trailing window.

    Contract semantics: absence of a cell means "not scored", never "closed"
    (SPEC-contract-notes, sparse-by-construction)."""
    con = lake.connect()
    cutoff = valid_from - timedelta(days=lookback_days)
    return con.execute(
        """
        SELECT DISTINCT tx_field, rx_field, band
        FROM labels
        WHERE window_start >= ? AND window_start < ?
        ORDER BY band, tx_field, rx_field
        """,
        [cutoff, valid_from],
    ).pl()


class ServingGBT:
    """Bare-cells OpennessModel adapter over a feature-frame GBTModel.

    M2's GBTModel.predict_p_open requires FEATURE_COLUMNS already joined
    (it raises ValueError otherwise); build_surface hands models bare cells
    (window_start, tx_field, rx_field, band). This adapter closes the gap by
    resolving features with feature_matrix at prediction time."""

    def __init__(self, inner, horizon_s: int, lake: Lake):
        self.model_id = inner.model_id
        self._inner = inner
        self._horizon_s = horizon_s
        self._lake = lake

    def predict_p_open(self, cells: pl.DataFrame) -> pl.DataFrame:
        from propagation.features.matrix import feature_matrix

        feats = feature_matrix(self._lake, cells, self._horizon_s)
        scored = self._inner.predict_p_open(feats)
        keys = ["window_start", "tx_field", "rx_field", "band"]
        return cells.join(scored.select(*keys, "p_open"), on=keys, how="left")


def _load_gbt_models(record: ModelRecord, lake: Lake) -> dict[int, "object"]:
    from propagation.models.gbt import GBTModel

    return {
        h: ServingGBT(GBTModel.load(_registry.model_file(record, h)), h, lake)
        for h in HORIZONS_S
    }


def run_once(
    lake: Lake,
    registry_dir: Path,
    surfaces_dir: Path,
    now: datetime,
    schema: dict,
    model_loader=None,
) -> Path:
    valid_from = window_floor(now)
    record = _registry.latest(registry_dir, "gbt-m2")
    models = (model_loader or _load_gbt_models)(record, lake)
    cells = scoring_cells(lake, valid_from)
    doc = build_surface(models, cells, valid_from, record)
    validate_surface(doc, schema)  # refuse to publish anything invalid
    return publish(doc, surfaces_dir)


def main() -> None:
    ap = argparse.ArgumentParser(prog="serve-score", description=__doc__)
    ap.add_argument("--once", action="store_true", help="run one scoring cycle")
    ap.add_argument("--lake-root", type=Path, default=Path("data/lake"))
    ap.add_argument("--registry", type=Path, default=Path("models/registry"))
    ap.add_argument("--surfaces-dir", type=Path, default=Path("surfaces"))
    ap.add_argument("--schema", type=Path, default=_SCHEMA_PATH)
    args = ap.parse_args()
    if not args.once:
        ap.error("daemon mode not implemented; run with --once (launchd fires every 15 min)")
    archive = run_once(
        Lake(args.lake_root),
        args.registry,
        args.surfaces_dir,
        now=datetime.now(UTC),
        schema=load_schema(args.schema),
    )
    print(f"published {archive}")
```

```python
"""Daily live scoreboard: yesterday's archived surfaces vs realized labels.

This is the ongoing honesty check (ROADMAP M4). Numbers here are expected to
differ from offline eval: the deployed nowcast scores cells whose
labeled-population membership is undefined at prediction time
(REVIEW-FINDINGS R2) — predictions that never receive a label are reported
as unmatched, not scored. Coverage (n_matched / n_pred) is therefore a
first-class output alongside Brier.
"""

from __future__ import annotations

import argparse
import json
from datetime import UTC, date, datetime, time, timedelta
from pathlib import Path

import polars as pl

from propagation.data.lake import Lake
from propagation.eval.metrics import brier

EXPECTED_SURFACES_PER_DAY = 96  # one per 15-min window

SCOREBOARD_HEADER = """\
# Live scoreboard

Daily join of archived prediction surfaces against realized labels.
Live Brier can differ from offline eval because of the eval-vs-serving
population shift (REVIEW-FINDINGS R2): negative-eligibility for a window is
only knowable after it closes, so some served predictions never get a label
and are excluded (see n_matched vs n_pred). Missing surfaces (Mac asleep,
job failed) show up in n_surfaces < expected — gaps are reported, never
silently skipped.

| date | band | horizon_s | surfaces | n_pred | n_abstain | n_matched | brier |
|---|---|---|---|---|---|---|---|
"""

_ROW_SCHEMA = {
    "window_start": pl.Datetime("us", "UTC"),
    "tx_field": pl.Utf8,
    "rx_field": pl.Utf8,
    "band": pl.Utf8,
    "horizon_s": pl.Int64,
    "p_open_pct": pl.Int64,
}


def _load_surface_rows(
    surfaces_dir: Path, target_day: date
) -> tuple[pl.DataFrame, dict[int, int]]:
    """Explode archived surfaces into per-cell prediction rows whose target
    window falls on target_day. Long horizons come from earlier surfaces."""
    rows: list[dict] = []
    found: dict[int, int] = {}
    for day_offset in (1, 0):  # yesterday's 24h-horizon surfaces target today
        gen_day = target_day - timedelta(days=day_offset)
        day_dir = surfaces_dir / f"{gen_day:%Y/%m/%d}"
        if not day_dir.exists():
            continue
        for f in sorted(day_dir.glob("*.json")):
            doc = json.loads(f.read_text())
            valid_from = datetime.strptime(
                doc["valid_from"], "%Y-%m-%dT%H:%M:%SZ"
            ).replace(tzinfo=UTC)
            cols = doc["columns"]
            for hi, h in enumerate(doc["horizons_s"]):
                target = valid_from + timedelta(seconds=h)
                if target.date() != target_day:
                    continue
                found[h] = found.get(h, 0) + 1
                for i in range(doc["n_cells"]):
                    rows.append(
                        {
                            "window_start": target,
                            "tx_field": cols["tx_field"][i],
                            "rx_field": cols["rx_field"][i],
                            "band": cols["band"][i],
                            "horizon_s": h,
                            "p_open_pct": cols["p_open_pct"][i][hi],
                        }
                    )
    return pl.DataFrame(rows, schema=_ROW_SCHEMA), found


def score_yesterday(
    lake: Lake, surfaces_dir: Path, target_day: date | None = None
) -> pl.DataFrame:
    target_day = target_day or (datetime.now(UTC).date() - timedelta(days=1))
    preds, found = _load_surface_rows(surfaces_dir, target_day)
    out: list[dict] = []
    if preds.height:
        con = lake.connect()
        labels = con.execute(
            "SELECT window_start, tx_field, rx_field, band, open FROM labels "
            "WHERE window_start >= ? AND window_start < ?",
            [
                datetime.combine(target_day, time(), tzinfo=UTC),
                datetime.combine(target_day + timedelta(days=1), time(), tzinfo=UTC),
            ],
        ).pl()
        for (band, h), grp in preds.group_by(  # type: ignore[misc]
            ["band", "horizon_s"], maintain_order=True
        ):
            scored = grp.drop_nulls("p_open_pct").join(
                labels, on=["window_start", "tx_field", "rx_field", "band"], how="inner"
            )
            n_matched = scored.height
            out.append(
                {
                    "date": target_day.isoformat(),
                    "band": band,
                    "horizon_s": h,
                    "n_surfaces": found.get(h, 0),
                    "surfaces_expected": EXPECTED_SURFACES_PER_DAY,
                    "n_pred": grp.height,
                    "n_abstain": grp["p_open_pct"].null_count(),
                    "n_matched": n_matched,
                    "brier": (
                        brier(
                            scored["open"].to_numpy(),
                            (scored["p_open_pct"] / 100).to_numpy(),
                        )
                        if n_matched
                        else None
                    ),
                    "base_rate": scored["open"].mean() if n_matched else None,
                }
            )
    return pl.DataFrame(
        out,
        schema={
            "date": pl.Utf8, "band": pl.Utf8, "horizon_s": pl.Int64,
            "n_surfaces": pl.Int64, "surfaces_expected": pl.Int64,
            "n_pred": pl.Int64, "n_abstain": pl.Int64, "n_matched": pl.Int64,
            "brier": pl.Float64, "base_rate": pl.Float64,
        },
    )


def main() -> None:
    ap = argparse.ArgumentParser(prog="scoreboard", description=__doc__)
    ap.add_argument("--lake-root", type=Path, default=Path("data/lake"))
    ap.add_argument("--surfaces-dir", type=Path, default=Path("surfaces"))
    ap.add_argument("--reports-dir", type=Path, default=Path("reports"))
    ap.add_argument("--date", type=date.fromisoformat, default=None,
                    help="target UTC day (default: yesterday)")
    args = ap.parse_args()
    df = score_yesterday(Lake(args.lake_root), args.surfaces_dir, args.date)
    args.reports_dir.mkdir(parents=True, exist_ok=True)
    (args.reports_dir / "scoreboard-latest.json").write_text(df.write_json())
    md = args.reports_dir / "scoreboard.md"
    if not md.exists():
        md.write_text(SCOREBOARD_HEADER)
    target = args.date or (datetime.now(UTC).date() - timedelta(days=1))
    with md.open("a") as f:
        if df.height == 0:
            f.write(f"| {target.isoformat()} | — | — | 0/{EXPECTED_SURFACES_PER_DAY} "
                    f"| 0 | 0 | 0 | — |\n")
        for r in df.iter_rows(named=True):
            b = f"{r['brier']:.4f}" if r["brier"] is not None else "—"
            f.write(
                f"| {r['date']} | {r['band']} | {r['horizon_s']} "
                f"| {r['n_surfaces']}/{r['surfaces_expected']} | {r['n_pred']} "
                f"| {r['n_abstain']} | {r['n_matched']} | {b} |\n"
            )
    print(df)


if __name__ == "__main__":
    main()
```

```python
"""Weekly guarded retrain: train all horizons, compare to the incumbent on
the trailing eval window, promote to the registry only if not worse on Brier
at every horizon (tolerance below). Comparison is logged either way."""

from __future__ import annotations

import argparse
import tempfile
from datetime import UTC, date, datetime, time, timedelta
from pathlib import Path

import polars as pl

from propagation.data.lake import Lake
from propagation.eval.metrics import brier
from propagation.eval.splits import GAP_HOURS
from propagation.features.labels import sample_training
from propagation.serving import registry
from propagation.serving.registry import ModelRecord
from propagation.serving.score import HORIZONS_S

MODEL_ID = "gbt-m2"
TOLERANCE = 0.002
EVAL_DAYS = 7


def should_promote(
    prev_brier: dict[int, float] | None,
    cand_brier: dict[int, float],
    tol: float = TOLERANCE,
) -> bool:
    if prev_brier is None:
        return True
    return all(
        cand_brier[h] <= prev_brier.get(h, float("inf")) + tol for h in cand_brier
    )


def density_and_bounds(
    train_labels: pl.DataFrame,
) -> tuple[pl.DataFrame, tuple[float, float]]:
    density = train_labels.group_by(["tx_field", "rx_field", "band"]).agg(
        pl.len().cast(pl.Int64).alias("n_labels")
    )
    lo = float(density["n_labels"].quantile(1 / 3))
    hi = float(density["n_labels"].quantile(2 / 3))
    return density, (lo, hi)


def _training_frame(lake: Lake, train_end: datetime) -> pl.DataFrame:
    """All labels before train_end, negative-sampled per SPEC §4.5 strata."""
    con = lake.connect()
    lab = con.execute(
        "SELECT * FROM labels WHERE window_start < ?", [train_end]
    ).pl()
    parts = []
    for (band, d), grp in lab.with_columns(
        pl.col("window_start").dt.date().alias("_d")
    ).group_by(["band", "_d"], maintain_order=True):
        parts.append(sample_training(grp.drop("_d"), band, d))
    return pl.concat(parts) if parts else lab.head(0)


def _eval_brier(model, lake: Lake, horizon_s: int, eval_labels: pl.DataFrame) -> float:
    # GBTModel.predict_p_open needs FEATURE_COLUMNS joined (M2); ServingGBT
    # resolves them and keeps keyed alignment instead of relying on row order.
    from propagation.serving.score import ServingGBT

    keys = ["window_start", "tx_field", "rx_field", "band"]
    pred = ServingGBT(model, horizon_s, lake).predict_p_open(eval_labels.select(keys))
    joined = eval_labels.join(pred, on=keys, how="inner").drop_nulls("p_open")
    return brier(joined["open"].to_numpy(), joined["p_open"].to_numpy())


def retrain(
    lake: Lake,
    registry_dir: Path,
    run_date: date,
    reports_dir: Path,
    horizons: list[int] = HORIZONS_S,
) -> ModelRecord | None:
    from propagation.models.gbt import GBTModel  # M2; imported late so pure-logic tests don't need it

    eval_start = datetime.combine(run_date - timedelta(days=EVAL_DAYS), time(), tzinfo=UTC)
    eval_end = datetime.combine(run_date, time(), tzinfo=UTC)
    train_end = eval_start - timedelta(hours=GAP_HOURS)

    con = lake.connect()
    eval_labels = con.execute(  # FULL unsampled label set — eval is never sampled
        "SELECT * FROM labels WHERE window_start >= ? AND window_start < ?",
        [eval_start, eval_end],
    ).pl()
    train_labels = _training_frame(lake, train_end)
    full_train = con.execute(
        "SELECT tx_field, rx_field, band FROM labels WHERE window_start < ?",
        [train_end],
    ).pl()
    density, bounds = density_and_bounds(full_train)

    try:
        prev = registry.latest(registry_dir, MODEL_ID)
    except FileNotFoundError:
        prev = None

    cand_brier: dict[int, float] = {}
    prev_brier: dict[int, float] | None = {} if prev else None
    model_files: dict[int, Path] = {}
    tmpdir = Path(tempfile.mkdtemp(prefix="retrain-"))
    for h in horizons:
        from propagation.features.matrix import feature_matrix

        feats = feature_matrix(lake, train_labels, h)
        model = GBTModel(h).fit(train_labels, feats)
        cand_brier[h] = _eval_brier(model, lake, h, eval_labels)
        out = tmpdir / f"model-h{h}.txt"
        model.save(out)
        model_files[h] = out
        if prev is not None:
            prev_model = GBTModel.load(registry.model_file(prev, h))
            assert prev_brier is not None
            prev_brier[h] = _eval_brier(prev_model, lake, h, eval_labels)

    promote = should_promote(prev_brier, cand_brier)
    version = run_date.strftime("%Y.%m.%d")
    trained_through = train_end.date() - timedelta(days=1)

    reports_dir.mkdir(parents=True, exist_ok=True)
    log = reports_dir / "retrain-log.md"
    if not log.exists():
        log.write_text(
            "# Retrain log\n\n"
            "| run | horizon_s | prev brier | candidate brier | promoted |\n"
            "|---|---|---|---|---|\n"
        )
    with log.open("a") as f:
        for h in horizons:
            pb = f"{prev_brier[h]:.4f}" if prev_brier else "—"
            f.write(
                f"| {version} | {h} | {pb} | {cand_brier[h]:.4f} "
                f"| {'yes' if promote else 'NO (guardrail)'} |\n"
            )

    if not promote:
        return None
    return registry.write_record(
        registry_dir, MODEL_ID, version, trained_through, model_files, density, bounds
    )


def main() -> None:
    ap = argparse.ArgumentParser(prog="retrain", description=__doc__)
    ap.add_argument("--lake-root", type=Path, default=Path("data/lake"))
    ap.add_argument("--registry", type=Path, default=Path("models/registry"))
    ap.add_argument("--reports-dir", type=Path, default=Path("reports"))
    ap.add_argument("--date", type=date.fromisoformat, default=None,
                    help="run date (default: today UTC)")
    args = ap.parse_args()
    run_date = args.date or datetime.now(UTC).date()
    rec = retrain(Lake(args.lake_root), args.registry, run_date, args.reports_dir)
    if rec is None:
        print("guardrail refused promotion; incumbent stays (see reports/retrain-log.md)")
        raise SystemExit(0)
    print(f"promoted {rec.model_id} {rec.version} (trained through {rec.trained_through})")


if __name__ == "__main__":
    main()
```

```markdown
# Consuming the prediction surface (cqdx adapter notes)

Audience: the closed-side adapter (cqdx → KV/D1 → "band outlook" UI;
pancetta band selection reads the same surface). This note is informative;
the normative contract is `contracts/prediction-surface.v1.schema.json` +
`docs/SPEC-contract-notes.md`. Nothing here overrides those. This repo
neither imports cqdx code nor knows cqdx exists beyond this boundary.

## Where the surface lives

The publisher writes every 15 minutes (launchd; see `ops/README.md`):

- **Stable URL / path:** `surfaces/current.json` — atomically replaced;
  a poll never observes a partial document.
- **Archive:** `surfaces/YYYY/MM/DD/HHMM.json` keyed by `valid_from`
  (UTC, minute ∈ {00,15,30,45}).

When published to object storage, the same layout applies under the bucket
prefix; serve with `Content-Encoding: gzip`. Poll the stable URL on your
own schedule (≥1/min is pointless; the document changes 4×/hour) and use
`generated_at` to detect change.

## Consumer obligations (normative list: SPEC-contract-notes §"Consumer obligations")

1. Hard-match `"schema": "propagation.prediction-surface.v1"` before parsing.
2. Ignore unknown properties (additive evolution within v1).
3. Treat `valid_until` (= `valid_from` + 30 min) as a hard staleness
   deadline — render "stale/no data", never a stale percentage.
4. `null` in a per-horizon slot = the model **abstains**: render "no data",
   never 0%. A cell absent from the surface = **not scored** (the universe
   is activity-gated): fall back to your own default (e.g. the P.533 grid
   cqdx already computes), labeled as such.
5. Do not interpolate between horizons without labeling it interpolation.

## Field notes for the adapter

- Columnar: element *i* of every array under `columns` is one directional
  path-cell `(tx_field → rx_field, band)`. `p_open_pct[i][j]` pairs with
  `horizons_s[j]`.
- `confidence`: 0/1/2 = low/medium/high training-data density for the cell.
  A UI should de-emphasize (or hide) tier 0.
- `model.version` / `model.trained_through` should be surfaced in any UI
  tooltip — the live scoreboard (`reports/scoreboard.md`) tracks honesty
  against realized labels per version.
- Serving-population caveat: the deployed nowcast scores cells whose
  label-population membership is unknowable at prediction time
  (`docs/REVIEW-FINDINGS.md` R2). Expect some scored cells to never
  receive ground truth; that is by design.

## Status of the contract

`prediction-surface.v1` is owned by this repo. Promotion/mirroring into
`dispensa` is pending an ADR there (proposed, not yet filed); until that
lands, this repo is the single source of truth and version bumps follow
`docs/SPEC-contract-notes.md` §"Versioning & evolution".
```
